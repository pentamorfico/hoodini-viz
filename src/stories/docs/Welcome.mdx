# Hoodini-Viz 🧬

**GPU-Accelerated Visualization Library for Comparative Genomics & Phylogenomics**

Hoodini-Viz is a high-performance React library for interactive visualization of phylogenetic trees, gene neighborhoods (synteny), protein domains, and homology relationships at genomic scale. Built on [deck.gl](https://deck.gl/) and WebGL, it enables fluid exploration of datasets with thousands of genes and complex evolutionary relationships.

---

## 🎯 Designed For

- **Comparative genomics** and synteny analysis
- **Gene neighborhood/cluster visualization** (genomic islands, operons, gene clusters)
- **Phylogenomics** and evolutionary studies
- **Protein domain architecture** visualization
- **Multi-scale genome browsers**

### Core Visualization Components

- 🌳 **Phylogenetic Tree** - Newick parsing, ultrametric conversion, customizable styling
- 🧬 **Genomic Neighborhoods** - Gene arrows with strand orientation, track alignment
- 🔬 **Protein Domains** - Multi-source annotations (Pfam, InterPro, CDD), polygon clipping
- 🔗 **Homology Links** - Protein similarity curves, nucleotide synteny blocks
- 📊 **Interactive Data Grid** - Virtualized browser for genes, domains, links

### Advanced Features

- 🎨 **50+ Color Palettes** - Qualitative, sequential, and diverging via dicopal
- 🔬 **3D Structure Prediction** - ESMFold (≤400aa) and Boltz2 (>400aa) integration
- 🧫 **RNA Structure Viewer** - NAview-inspired secondary structure visualization
- 📤 **Publication-Ready Export** - SVG with format guides (A4, Letter, custom)
- 🌙 **Theme Support** - Light/dark mode with system preference detection

## 🚀 Quick Start

```bash
npm install hoodini-viz
```

### Full Dashboard (Recommended)

```tsx
import { HoodiniDashboard } from 'hoodini-viz';

function App() {
  return (
    <HoodiniDashboard
      dataPaths={{
        gffParquet: '/data/genes.parquet',
        hoodsParquet: '/data/hoods.parquet',
        newick: '/data/tree.nwk',
      }}
      showSidebar={true}
    />
  );
}
```

### Core Visualization Only

```tsx
import { HoodiniViz } from 'hoodini-viz';

function App() {
  return (
    <HoodiniViz
      newickStr={newickData}
      gffFeatures={genes}
      proteinLinks={links}
      genePalette={{ type: 'qualitative', name: 'Bold', numColors: 8, enabled: true }}
      onObjectClick={(info) => console.log('Clicked:', info.object)}
    />
  );
}
```

## 📤 SVG Export

1. Enable **Format Guides** in sidebar
2. Select format preset (A4, Letter, PowerPoint, etc.)
3. Adjust view to fit content within guides
4. Click **Export SVG**

Export features:
- Scale to format dimensions
- Crop to guide bounds
- Cross-application compatibility (Illustrator, Affinity, Inkscape)
- High-DPI output for print (300 DPI)
