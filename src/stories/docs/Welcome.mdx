# Welcome to Hoodini-Viz

**Hoodini-Viz** is a React library for visualizing genomic neighborhoods with phylogenetic context.

## Features

- 🌳 **Phylogenetic Tree** - Interactive tree with customizable labels and colors
- 🧬 **Genomic Neighborhoods** - Visualize genes, domains, and synteny links
- 🔗 **Protein & Nucleotide Links** - Show homology relationships between sequences
- 🎨 **Color Palettes** - Customizable color schemes for domains and clusters
- 📊 **Data Grids** - Tabular views for detailed inspection
- 🔬 **3D Structures** - ESMFold protein structure viewer
- 📤 **Export** - SVG export for publication-quality figures

## Quick Start

```bash
npm install hoodini-viz
```

```tsx
import { HoodiniVizDash } from 'hoodini-viz';
import 'hoodini-viz/dist/style.css';

function App() {
  return <HoodiniVizDash />;
}
```
