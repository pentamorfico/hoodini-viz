# API Reference

Complete documentation for all Hoodini-Viz components, props, and types.

---

## Components

### HoodiniDashboard

The full-featured dashboard with automatic data loading, sidebar controls, and data grid.

```tsx
import { HoodiniDashboard } from 'hoodini-viz';

<HoodiniDashboard
  dataPaths={{
    gffParquet: '/data/genes.parquet',
    hoodsParquet: '/data/hoods.parquet',
    newick: '/data/tree.nwk',
  }}
  initialState={{
    ultrametric: true,
    colorBy: 'cluster',
  }}
  showSidebar={true}
  showDataGrid={true}
  onDataLoaded={(data) => console.log('Data loaded:', data)}
/>
```

#### DataPaths

| Property | Type | Description |
|----------|------|-------------|
| `gffParquet` | `string` | Path to GFF features parquet file |
| `gffText` | `string` | Path to GFF features text file (fallback) |
| `hoodsParquet` | `string` | Path to hoods parquet file |
| `hoodsText` | `string` | Path to hoods TSV file (fallback) |
| `newick` | `string` | Path to Newick tree file |
| `proteinLinksParquet` | `string` | Path to protein links parquet file |
| `proteinLinksText` | `string` | Path to protein links TSV file |
| `nucleotideLinksParquet` | `string` | Path to nucleotide links parquet file |
| `domainsParquet` | `string` | Path to domains parquet file |
| `proteinMetadataParquet` | `string` | Path to protein metadata parquet file |
| `treeMetadataParquet` | `string` | Path to tree metadata parquet file |

#### Dashboard Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `dataPaths` | `DataPaths` | - | Paths to data files |
| `initialState` | `InitialState` | `{}` | Initial visualization state |
| `showSidebar` | `boolean` | `true` | Show control sidebar |
| `showDataGrid` | `boolean` | `true` | Show data browser panel |
| `showToolbar` | `boolean` | `true` | Show toolbar |
| `onDataLoaded` | `(data) => void` | - | Callback when data finishes loading |
| `ref` | `Ref<HoodiniDashboardRef>` | - | Imperative handle for programmatic control |

### HoodiniViz

The core visualization component. Props-driven, no internal data loading.

```tsx
import { HoodiniViz } from 'hoodini-viz';
```

#### Data Props

| Prop | Type | Description |
|------|------|-------------|
| `newickStr` | `string` | Newick format phylogenetic tree |
| `gffFeatures` | `GFFFeature[]` | Parsed GFF3 gene features |
| `proteinLinks` | `ProteinLink[]` | Protein-protein homology links |
| `nucleotideLinks` | `NucleotideLink[]` | Nucleotide synteny blocks |
| `domainsByGene` | `Record<string, Domain[]>` | Domain annotations by gene ID |
| `hoods` | `Hood[]` | Genomic neighborhood definitions |
| `proteinMetadata` | `Record<string, object>` | Gene metadata (clusters, products, sequences) |
| `treeMetadata` | `Record<string, object>` | Tree leaf metadata (taxonomy, etc.) |

#### Visual Settings Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `ultrametric` | `boolean` | `false` | Render tree as ultrametric |
| `geneHeight` | `number` | `60` | Height of gene arrows (pixels) |
| `arrowheadHeight` | `number` | `0` | Arrowhead height (0 = proportional) |
| `treeXScale` | `number` | `100` | Tree horizontal scale (%) |
| `phyloLabelPosition` | `'after-tree' \| 'after-tracks'` | `'after-tree'` | Position of tree labels |
| `alignLabels` | `boolean` | `true` | Align tree labels to same X |
| `geneLabelPosition` | `'top' \| 'bottom' \| 'center'` | `'bottom'` | Gene label position |

#### Alignment Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `alignCluster` | `string \| null` | `null` | Cluster ID to align by |
| `useDefaultGeneAlignment` | `boolean` | `true` | Use align_gene from hoods |
| `defaultAlign` | `'start' \| 'center' \| 'end'` | `'start'` | Fallback alignment |

#### Coloring Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `colorBy` / `geneColorBy` | `string` | `'cluster'` | Gene color-by field |
| `labelBy` / `geneLabelBy` | `string` | - | Gene label field |
| `treeColorBy` | `string` | - | Tree label color-by field |
| `treeLabelBy` | `string` | - | Tree label field |
| `domainColorBy` | `string` | `'domainName'` | Domain color-by field |
| `domainSource` | `string` | `'all'` | Domain source filter |

#### Palette Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `genePalette` | `PaletteConfig` | Bold | Gene coloring palette |
| `domainPalette` | `PaletteConfig` | Gray | Domain coloring palette |
| `phyloPalette` | `PaletteConfig` | Vivid | Tree label palette |
| `ncRNAPalette` | `PaletteConfig` | Prism | ncRNA coloring palette |
| `regionPalette` | `PaletteConfig` | Margot2 | Region coloring palette |

#### Layer Visibility Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `showTreeLayer` | `boolean` | `true` | Show phylogenetic tree |
| `showGeneLayer` | `boolean` | `true` | Show gene arrows |
| `showDomainLayer` | `boolean` | `true` | Show protein domains |
| `showProteinLinkLayer` | `boolean` | `true` | Show protein links |
| `showNucleotideLinkLayer` | `boolean` | `true` | Show synteny blocks |
| `showNcRNALayer` | `boolean` | `true` | Show ncRNA features |
| `showRegionsLayer` | `boolean` | `true` | Show region annotations |
| `showGeneTextLayer` | `boolean` | `true` | Show gene labels |
| `showTreeTextLayer` | `boolean` | `true` | Show tree labels |
| `showRuler` | `boolean` | `true` | Show position ruler |
| `showScrollbar` | `boolean` | `true` | Show vertical scrollbar |
| `showConnectingLines` | `boolean` | `false` | Show tree-to-track lines |

#### Link Configuration Props

| Prop | Type | Description |
|------|------|-------------|
| `proteinLinkConfig` | `ProteinLinkConfig` | Protein link visualization config |
| `nucleotideLinkConfig` | `NucleotideLinkConfig` | Nucleotide link visualization config |

#### Callback Props

| Prop | Type | Description |
|------|------|-------------|
| `onObjectClick` | `(info) => void` | Click handler for features |
| `onLegendChange` | `(data) => void` | Legend data change handler |
| `setGenomeViewRef` | `(gv) => void` | Receive GenomeView instance |

## Types

### PaletteConfig

```typescript
interface PaletteConfig {
  type: 'qualitative' | 'sequential' | 'diverging';
  name: string;              // Palette name (e.g., 'Bold', 'viridis')
  numColors?: number;        // Number of colors to use
  reverse?: boolean;         // Reverse palette order
  enabled?: boolean;         // Whether palette is active
  alphaRange?: [number, number];  // Alpha range [min, max] for sequential
}
```

### ProteinLinkConfig

```typescript
interface ProteinLinkConfig {
  colorBy?: 'source_gene' | 'target_gene' | 'identity_solid' | 'identity_gradient';
  solidColor?: [number, number, number, number];  // RGBA
  useAlpha?: boolean;
  minAlpha?: number;         // 0-1
  maxAlpha?: number;         // 0-1
  palette?: PaletteConfig;
}
```

### NucleotideLinkConfig

```typescript
interface NucleotideLinkConfig {
  colorBy?: 'solid' | 'identity_gradient';
  solidColor?: [number, number, number, number];
  strandColoring?: boolean;  // Different colors for same/opposite strand
  sameStrandColor?: [number, number, number, number];
  oppositeStrandColor?: [number, number, number, number];
  useAlpha?: boolean;
  minAlpha?: number;
  maxAlpha?: number;
}
```

### Hood

```typescript
interface Hood {
  hood_id: string;
  seqid: string;

  end: number;

}
```

### ProteinLink

```typescript
interface ProteinLink {
  gAId: string;              // First gene ID

}
```

### NucleotideLink

```typescript
interface NucleotideLink {
  seqidA: string;
  startA: number;

```

### Domain

```typescript
interface Domain {
  geneId: string;
  domainName: string;
  start: number;             // Amino acid position
  end: number;
  source: string;            // Pfam, TIGRFAM, CDD, etc.
  evalue?: number;
  coverage?: number;         // 0-1
}
```

### GFFFeature

```typescript
interface GFFFeature {
  seqid: string;
  source: string;
  type: string;              // CDS, ncRNA, region, etc.
  start: number;
  end: number;

  strand: '+' | '-';
  phase: string | null;
  attributes: Record<string, string>;

```

### FormatPreset

```typescript
interface FormatPreset {
  id: string;
  name: string;
  width: number;
  height: number;

  category?: 'print' | 'screen' | 'presentation';
}
```

```typescript
// Parse GFF3 text
const features = parseGFF(gffString);

const hoods = parseHoods(tsvString);

const proteinLinks = parseLinks(linksTsv);
```

```typescript
import { 
  getPaletteColors,
```

## Models

### PhyloTree

```typescript
import { PhyloTree } from 'hoodini-viz';

const tree = new PhyloTree(newickString, config, ultrametric);

// Properties
tree.root;        // Root PhyloNode
tree.allNodes;    // All nodes array
tree.leafNodes;   // Leaf nodes only
tree.hasTree;     // True if Newick was parsed

// Methods
tree.makeUltrametric();  // Convert to ultrametric
```

### GenomeView

```typescript
import { GenomeView } from 'hoodini-viz';

// GenomeView manages visualization state
genomeView.genesById;       // Map of gene ID → Gene
genomeView.hoodRanges;      // Map of hood ID → Hood
genomeView.proteinLinks;    // ProteinLink array
genomeView.domainsByGene;   // Map of gene ID → Domain[]

// Methods
genomeView.flipTrackToggle(hoodId);     // Flip track orientation
genomeView.shiftTrackPlus1kb(hoodId);   // Shift track window
```

## Configuration

### DEFAULT_CONFIG

```typescript
import { DEFAULT_CONFIG, createConfig } from 'hoodini-viz';

// Customize configuration
const customConfig = createConfig({
  gene: {
    height: 80,
    arrowheadHeight: 15,
  },
  tree: {
    ySpacing: 200,
    xScalePercent: 50,
  },
  proteinLink: {
    bezierSegments: 60,  // Reduce for performance
    minAlpha: 0.1,
    maxAlpha: 0.6,
  },
});
```

### Config Sections

| Section | Description |
|---------|-------------|
| `tree` | Tree layout: ySpacing, xScalePercent, edgeColor |
| `gene` | Gene styling: height, arrowheadHeight, tipWidthFactor |
| `domain` | Domain styling: heightFactor, edgeWidth |
| `proteinLink` | Link styling: bezierSegments, color, alpha range |
| `nucleotideLink` | Synteny styling: color, strand colors |
| `theme` | Theme colors: light and dark mode |
| `colorPalettes` | Default palettes for each layer |
