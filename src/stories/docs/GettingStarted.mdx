# Getting Started

## Installation

```bash
npm install hoodini-viz
```

## Basic Usage

### Option 1: Full Dashboard (Recommended)

The dashboard includes a sidebar with all controls for visualization, data loading, and export.

```tsx
import { HoodiniVizDash } from 'hoodini-viz';
import 'hoodini-viz/dist/style.css';

function App() {
  return <HoodiniVizDash />;
}
```

### Option 2: Core Visualization Only

For custom integrations, use the core component with your own data.

```tsx
import HoodiniViz from 'hoodini-viz';

function App() {
  return (
    <HoodiniViz
      gffFeatures={gffData}
      hoods={hoodsData}
      newickStr={treeNewick}
      proteinLinks={proteinLinks}
      nucleotideLinks={nucleotideLinks}
      domainsByGene={domains}
      regionFeatures={regions}
      // Visual settings
      ySpacing={150}
      genomeXScale={30}
      geneHeight={60}
      phyloLabelSize={20}
      geneLabelSize={12}
      // Layer visibility
      showTreeLayer={true}
      showGeneLayer={true}
      showDomainLayer={true}
      showProteinLinkLayer={true}
      showNucleotideLinkLayer={true}
      // Palettes
      genePalette={{ type: 'qualitative', name: 'Bold', numColors: 8, enabled: true }}
      phyloPalette={{ type: 'qualitative', name: 'Vivid', numColors: 8, enabled: true }}
      regionPalette={{ type: 'qualitative', name: 'Margot2', numColors: 8, enabled: true }}
      ncRNAPalette={{ type: 'qualitative', name: 'Prism', numColors: 8, enabled: true }}
    />
  );
}
```

## Data Formats

### GFF3 (Genes and ncRNAs)

```
seqid    source    type    start    end    score    strand    phase    attributes
contig_A    hoodini    CDS    1000    2500    .    +    .    ID=gene_A1;Name=proteinA1;cluster=cluster_001
contig_A    hoodini    ncRNA    3000    3100    .    +    .    ID=ncrna_1;Name=tRNA-Ala;ncRNA_class=tRNA
```

### Hoods (TSV)

```
hood_id    seqid    start    end    align_gene
1    contig_A    0    10000    gene_A3
2    contig_B    0    12000    gene_B5
```

### Newick Tree

```
((contig_A:0.1,contig_B:0.15):0.05,contig_C:0.2);
```

### Protein Links (BLAST/Diamond output)

```
gene_id_1    gene_id_2    identity    evalue    bitscore
gene_A1    gene_B1    85.5    1e-50    250
gene_A2    gene_C2    72.3    1e-30    180
```

### Nucleotide Links (Synteny)

```
seqid_1    start_1    end_1    seqid_2    start_2    end_2    strand_1    strand_2    identity
contig_A    1000    5000    contig_B    2000    6000    +    +    92.5
```

### Domains (TSV)

```
gene_id    domain_id    start    end    evalue    source
gene_A1    PF00001    10    150    1e-20    Pfam
gene_A1    TIGR00123    200    350    1e-15    TIGRFAM
```

### Regions (GFF3)

```
seqid    source    type    start    end    score    strand    phase    attributes
contig_A    CRISPRCasFinder    CRISPR    5000    5500    .    .    .    ID=crispr_1;Name=CRISPR_array
contig_B    PHASTER    prophage    8000    25000    .    .    .    ID=prophage_1;Name=Prophage_region
```

## Visual Settings

### Y Spacing

Controls vertical distance between tracks. Useful for adjusting density.

```tsx
<HoodiniViz ySpacing={150} /> // Default: 150
```

### Genome X Scale

Controls horizontal compression/expansion of genomic coordinates.

```tsx
<HoodiniViz genomeXScale={30} /> // Default: 30 (30% of original)
```

### Gene Height

Height of gene arrows in world coordinates.

```tsx
<HoodiniViz geneHeight={60} /> // Default: 60
```

### Label Sizes

```tsx
<HoodiniViz 
  phyloLabelSize={20}  // Tree leaf labels
  geneLabelSize={12}   // Gene metadata labels
/>
```

## Format Guides & Export

### Enabling Format Guides

Format guides help you prepare figures for publication or presentation.

```tsx
<HoodiniViz
  showFormatGuides={true}
  formatGuidePreset={{ id: 'a4-portrait', name: 'A4 Portrait', width: 210, height: 297, unit: 'mm' }}
  scaleExportToFormat={true}
  cropToGuides={true}
/>
```

### Available Presets

| Preset | Dimensions | Use Case |
|--------|------------|----------|
| A4 Portrait | 210×297mm | Papers, reports |
| A4 Landscape | 297×210mm | Wide figures |
| A3 Portrait | 297×420mm | Posters |
| Letter Portrait | 216×279mm | US papers |
| PowerPoint 16:9 | 1920×1080px | Presentations |
| HD 1080p | 1920×1080px | Screen display |

## Layer Controls

Toggle visibility of different visualization layers:

```tsx
<HoodiniViz
  showTreeLayer={true}
  showGeneLayer={true}
  showDomainLayer={true}
  showProteinLinkLayer={true}
  showNucleotideLinkLayer={true}
  showNcRNALayer={true}
  showRegionLayer={true}
/>
```

## Filtering

### Prevalence Filter

Filter genes by how common their cluster is across the dataset.

```tsx
<HoodiniViz
  prevalenceThreshold={10}  // Show only clusters present in ≥10% of hoods
/>
```

## Theme

```tsx
<HoodiniViz
  theme="light"  // or "dark"
/>
```
