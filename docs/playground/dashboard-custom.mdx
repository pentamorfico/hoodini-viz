# Dashboard (Custom Palettes)

Customize the appearance of `HoodiniDashboard` with custom color palettes and styling options.

## Available Built-in Palettes

### Qualitative (for categories)

| Name | Best For | Colors |
|------|----------|--------|
| `tableau10` | General use | 10 distinct colors |
| `category10` | D3 default | 10 colors |
| `set1` | ColorBrewer | 9 bold colors |
| `set2` | ColorBrewer | 8 pastel colors |
| `set3` | ColorBrewer | 12 colors |
| `paired` | Paired data | 12 paired colors |
| `dark2` | Dark theme | 8 dark colors |

### Sequential (for continuous data)

| Name | Best For |
|------|----------|
| `viridis` | Perceptually uniform |
| `plasma` | High contrast |
| `inferno` | Dark to bright |
| `magma` | Purple-orange |
| `blues` | Single hue |
| `greens` | Single hue |
| `oranges` | Single hue |

## Full Example

```tsx
import { HoodiniDashboard, type HoodiniDashboardProps } from 'hoodini-viz';
import 'hoodini-viz/style.css';

const config: HoodiniDashboardProps = {
  dataPaths: {
    newick: '/data/tree.nwk',
    gffParquet: '/data/gff.parquet',
    hoodsParquet: '/data/hoods.parquet',
    proteinLinksParquet: '/data/protein_links.parquet',
  },
  
  // Initial visualization state
  initialState: {
    showDomains: true,
    showProteinLinks: true,
    colorBy: 'annotation',
  },
  
  // Color palette
  palette: {
    name: 'tableau10',
  },
  
  // Protein link styling
  proteinLinkConfig: {
    color: [100, 149, 237, 150],
    width: 1.5,
  },
};

function App() {
  return <HoodiniDashboard {...config} />;
}
```
