# Custom Palettes

Dashboard with pre-configured color palettes for genes and domains.

<DashboardCustomPaletteDemo />

## Code

```jsx
<HoodiniDashboard
  dataPaths={dataPaths}
  initialState={{
    genePalette: { type: 'qualitative', name: 'Vivid', numColors: 12, enabled: true },
    domainPalette: { type: 'qualitative', name: 'Set1', numColors: 9, enabled: true },
    geneColorBy: 'cluster',
    domainColorBy: 'domainName',
  }}
/>
```
