# Protein & DNA Links

Dashboard highlighting synteny relationships with protein and nucleotide links.

<DashboardLinksDemo />

## Code

```jsx
<HoodiniDashboard
  dataPaths={dataPaths}
  initialState={{
    showProteinLinkLayer: true,
    showNucleotideLinkLayer: true,
    genePalette: { type: 'qualitative', name: 'Set2', numColors: 8, enabled: true },
    geneColorBy: 'cluster',
    proteinLinkConfig: { 
      colorBy: 'source_gene', 
      useAlpha: true, 
      minAlpha: 0.1, 
      maxAlpha: 0.6 
    },
  }}
/>
```
