# HoodiniViz Standalone

The core `HoodiniViz` component for advanced users who want full control over the visualization without the sidebar UI.

import { Callout, Tabs } from 'nextra/components'

<Callout type="warning">
  `HoodiniViz` requires you to provide pre-processed data directly. For automatic data loading, use `HoodiniDashboard` instead.
</Callout>

## When to Use HoodiniViz

Choose `HoodiniViz` when you need:

- **Custom UI** - Build your own controls and sidebar
- **Data preprocessing** - Transform data before visualization
- **Multiple instances** - Sync multiple visualizations
- **Performance control** - Fine-grained control over rendering

import { HoodiniViz, type HoodiniVizProps } from 'hoodini-viz';
import 'hoodini-viz/style.css';

// You must provide parsed data, not URLs
const vizProps: HoodiniVizProps = {
  // Newick string (parsed from file)
  newickStr: '((Genome_A:0.1,Genome_B:0.2):0.3,(Genome_C:0.15,Genome_D:0.25):0.35);',
  
  // GFF features array
  gffFeatures: [

      source: 'prodigal',
      type: 'CDS',
      start: 1000,
      end: 2500,
      strand: '+',
      attributes: { product: 'hypothetical protein', locus_tag: 'GENE_001' }
    },
    // ... more features
  ],
  
  // Neighborhood definitions
  hoods: [
    { genome: 'Genome_A', contig: 'contig_1', start: 0, end: 10000, anchor: 'GENE_001' },
    { genome: 'Genome_B', contig: 'contig_1', start: 5000, end: 15000, anchor: 'GENE_002' },
    // ... more hoods
  ],
  
  // Optional: links and domains
  proteinLinks: [],
  nucleotideLinks: [],
  domains: [],
  
  // Configuration
  config: {
    geneHeight: 20,
    geneSpacing: 5,
    showDomains: true,
  }
};

function App() {
  return (
    <div style={{ width: '100%', height: '100vh' }}>
      <HoodiniViz {...vizProps} />
    </div>
  );
}

## HoodiniViz Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `newickStr` | `string` | ✅ | Newick format tree string |
| `gffFeatures` | `GFFFeatureData[]` | ✅ | Array of GFF feature objects |
| `hoods` | `HoodData[]` | ✅ | Array of neighborhood definitions |
| `proteinLinks` | `ProteinLinkData[]` | ❌ | Protein similarity links |
| `nucleotideLinks` | `NucleotideLinkData[]` | ❌ | Nucleotide similarity links |
| `domains` | `DomainData[]` | ❌ | Protein domain annotations |
| `colorMap` | `ColorMap` | ❌ | Custom color mapping |
| `config` | `StyleConfig` | ❌ | Visualization configuration |
| `onNodeClick` | `(node) => void` | ❌ | Callback when tree node clicked |
| `onGeneClick` | `(gene) => void` | ❌ | Callback when gene clicked |

## Data Types

```ts
interface GFFFeatureData {
  seqid: string;
  source: string;
  type: string;
  start: number;
  end: number;
  strand: '+' | '-' | '.';
  attributes?: Record<string, string>;
}

interface HoodData {
  genome: string;      // Must match tree leaf name
  contig: string;
  start: number;
  end: number;
  anchor: string;      // Anchor gene locus_tag
}

interface ProteinLinkData {
  source_gene: string;
  target_gene: string;
  identity: number;
  e_value?: number;
}
```

## Comparison: HoodiniDashboard vs HoodiniViz

| Feature | HoodiniDashboard | HoodiniViz |
|---------|------------------|------------|
| Data loading | ✅ Automatic | ❌ Manual |
| Sidebar UI | ✅ Included | ❌ None |
| Parquet support | ✅ Built-in | ❌ Pre-process required |
| Custom UI | ⚠️ Limited | ✅ Full control |
| Bundle size | Larger | Smaller |
